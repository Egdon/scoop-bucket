# scoop-bucket

**简体中文** | [English](#english)

[tapefox](https://github.com/Egdon/tapefox) 的 Scoop 软件源。tapefox 是磁带卡座风格的命令行网易云音乐客户端。

```powershell
scoop bucket add egdon https://github.com/Egdon/scoop-bucket
scoop install tapefox
```

`bucket/` 中的文件由 tapefox 的发布流程自动生成，请勿手动修改。

## English

Scoop bucket for [tapefox](https://github.com/Egdon/tapefox), a terminal client for NetEase Cloud Music with a cassette-deck interface.

```powershell
scoop bucket add egdon https://github.com/Egdon/scoop-bucket
scoop install tapefox
```

The files in `bucket/` are generated by the tapefox release workflow and should not be edited by hand.
