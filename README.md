# scoop-bucket

**简体中文** | [English](#english)

[musicfox-deck](https://github.com/Egdon/musicfox-deck) 的 Scoop 软件源。musicfox-deck 是磁带卡座风格的命令行网易云音乐客户端。

```powershell
scoop bucket add egdon https://github.com/Egdon/scoop-bucket
scoop install musicfox-deck
```

`bucket/` 中的文件由 musicfox-deck 的发布流程自动生成，请勿手动修改。

## English

Scoop bucket for [musicfox-deck](https://github.com/Egdon/musicfox-deck), a terminal client for NetEase Cloud Music with a cassette-deck interface.

```powershell
scoop bucket add egdon https://github.com/Egdon/scoop-bucket
scoop install musicfox-deck
```

The files in `bucket/` are generated by the musicfox-deck release workflow and should not be edited by hand.
